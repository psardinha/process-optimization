# Process Optimization

An MLOps project focused on automating machine learning workflows for process optimization using AWS SageMaker, Amazon S3, GitHub Actions and Terraform.

**Status:** Under development.

## Planned features

* Automated model training with AWS SageMaker.
* GitHub Actions workflows for training automation.
* S3-triggered retraining when new training data is uploaded.
* Infrastructure provisioning and management with Terraform.
* Model evaluation and deployment automation.
